## What This Is

**Fynans** is a Flutter personal finance tracker app for Android. It reads bank transaction SMS messages, parses them automatically, and lets users manually add/categorize transactions. Data is stored locally with Hive. Auth is handled by AWS Cognito via Amplify.

## Common Commands

```bash
# Install dependencies
flutter pub get

# Run on connected Android device
flutter run -d android

# Run with a specific device/emulator
flutter run

# Lint
flutter analyze

# Run tests
flutter test

# Run a single test file
flutter test test/widget_test.dart

# Regenerate Hive adapters (required after editing any @HiveType model)
dart run build_runner build --delete-conflicting-outputs
```

## Architecture

### Entry Point & Auth (`lib/main.dart`)
Initializes Hive, registers the `Transaction` adapter, opens the `'transactions'` box, and calls `Amplify.configure()` using `amplify_outputs.dart` (gitignored — generated by Amplify CLI). Auth state is checked via `Amplify.Auth.fetchAuthSession()` and routes to `LoginScreen` or `MainScreen`.

### Navigation Shell (`lib/main_screen.dart`)
A `BottomNavigationBar` with 3 tabs hosted in an `IndexedStack`:
1. **Expenses** — `TransactionsListScreen` (with `TransactionCubit` + `AdvancedViewBloc` provided)
2. **Analytics** — `AnalyticsScreen`
3. **TestSMS** — `TestSmsScreen` (dev/debug screen for testing SMS parsing)

### State Management (`lib/blocs/`)
Uses `flutter_bloc`:
- **`TransactionCubit`** — Fetches transactions for the selected month using `HiveService.listenToTransactionsForMonth()` (stream-based, reacts to Hive box changes). Emits `MonthlySummary`.
- **`AdvancedViewBloc`** — Handles filtering, hierarchical grouping of transactions into `HierarchyNode` trees. Grouping is done client-side after fetching. Events: `DataFetched`, `MonthChanged`, `HierarchyChanged`, `GroupFilterChanged`, `TagFilterChanged`, `PartyFilterChanged`.

### Data Layer (`lib/services/hive_service.dart`)
`HiveService` is the sole data access layer over the Hive `'transactions'` box. All filtering (by month, group, tag, party) happens in Dart since Hive has no query engine. Key methods: `saveTransaction`, `deleteTransaction`, `listenToTransactionsForMonth` (stream), `fetchTransactionsForMonth` (future), `getAdvancedViews`, `getAnalyticsForMonth`.

### SMS Pipeline (`lib/services/`)
- **`ReadSmsService`** — Requests SMS permission, fetches the last 200 inbox messages, filters by `last_read_timestamp` stored in `SharedPreferences`.
- **`SmsParserService`** — Stateless parser. Checks sender against a whitelist of Indian bank sender IDs (ICICI, HDFC, SBI, etc.), applies inclusion/exclusion keyword rules, then extracts `amount`, `balance`, `accountNumber`, and `merchant` via regex. Returns a `ParsedTransactionDetails`.
- **`ParsedTransaction`** — Data class with `TransactionType` enum (debit, credit, declined, unknown).

### Models (`lib/models/`)
- **`Transaction`** (`@HiveType(typeId: 0)`) — Core model. Fields: `amount`, `date`, `tags` (List), `group` (List, comma-separated on input), `party`, `isCredit`, `note`. **Do not change `typeId` without a migration.**
- `transaction.g.dart` — Code-generated Hive adapter. Regenerate with `build_runner` after any `@HiveField` changes.
- **`GroupingOption`** (enum) — `group`, `tag`, `party`, `month`. Each value implements `getValues(Transaction)` for hierarchical grouping logic.
- `MonthlySummary`, `MonthlyAnalytics`, `AdvancedViewSummary` — Computed aggregates.

### UI (`lib/screens/`, `lib/widgets/`)
- `TransactionsListScreen` — Swipeable `PageView` of months (5-year range), toggles between **Simple** (flat list) and **Advanced** (hierarchical tree) view modes.
- `AddTransactionScreen` — Form with autocomplete for group and party fields sourced from existing Hive data.
- `AnalyticsScreen` — Bar chart (daily spending) + pie chart (spending by tag) using `fl_chart`.
- `TagHelper` (`lib/utils/tag_helper.dart`) — Centralized map of predefined tag names → icons/colors. Add new tags here.

### Backend (`amplify/`)
TypeScript Amplify backend config. Auth uses AWS Cognito. `amplify_outputs.dart` must exist locally (run `ampx generate outputs` or equivalent) — it is gitignored.
